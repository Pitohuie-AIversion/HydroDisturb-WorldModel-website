# FlowScope 3D V2.0 设计书复核

2026-11-18，按展示目录中的 `flowworldshowdesign.md` 复核。下列七章全屏性能记录对应播放修订版 r2。性能目标是 1080p 交互至少 30 FPS，一帧的时间预算约为 33.3 ms。流场数据另按物理时间换帧。

## r7 的高刷新率回放

第一章仍用约 8 秒演示全部 81 个归档。正常窗口随浏览器的显示回调绘制。可见的内置窗口若把页面的显示回调降到低频，渲染器会向专用 Worker 请求显示节拍，每次完成绘制后再请求下一次。暂停、隐藏或恢复正常页面节拍时停止 Worker。没有相应浏览器能力的设备使用本地计时器。归档端点和相邻过渡共同使用原网格缓冲。完整一轮的缓冲上传量由 90.0 MB 降至 48.8 MB。

在同一台 RTX 5060 的 Codex 内置窗口中，固定相机对 144×72 像素的尾流区域读取整段回放。r6 的绘图区约 724×355，r7 约 739×376。r6 每秒约有 58.8 幅实质变化的图像，r7 在 8.051 秒内读到 1642 幅，约 203.8 幅/秒。更新间隔 P95 从 27.2 毫秒降到 6.5 毫秒。r7 整段最长间隔为 30.8 毫秒。两次均经过全部 81 个归档。测量对象为三维绘图缓冲区，显示器最终呈现的帧数未单独采集。

固定视角的 8 秒录像也提供 120 FPS 版本，浏览器按 H.264 解码能力选择 120 或 60 FPS。120 FPS 录像从第 0 帧到第 960 帧逐一解码，81 个原始端点与源图全部匹配，每个相邻输出帧都有不同像素。

## r6 的回放时长与涡面过渡

第一章默认将相邻归档的播放间隔设为 0.1 秒，80 个间隔合计 8 秒。圆柱绕流仍从真实 0.00 s 到 60.00 s。归档端点绘制原始 Q 等值面。在端点之间，用相邻网格的双向顶点对应对位置、法向和显示颜色做插值，画面以 ≈ 标注档间时刻。单步和手动选时显示归档数据，右侧物理读数与测点对应归档。菜单中的物理倍速按原始 `time_s` 播放。

七章讲解将同一批归档均匀安排到第一章，60.00 s 的末帧在切章前停留约 0.45 秒。无 WebGL 的设备默认播放 8 秒固定视角录像，实测图像之间作渐变。

在实际 Codex 内置窗口对原来停顿明显的稀疏段做了固定相机复测。窗口可见、未聚焦，使用 RTX 5060，绘图区为 724×354。20.04–49.92 物理秒的范围内，1.483 秒提交了 87 个不同涡面状态。另一次只读取尾流像素的复测中，1.495 秒内读取到 88 幅不同图像，画面变化约 58 次/秒，间隔 P95 为 27.3 毫秒，最长 28.5 毫秒。该指标取自三维绘图缓冲区，显示器端的最终呈现频率未单独测量。

## r5 的第一章全程回放

打开第一章即从 0.00 s 的初始条件开始。自由探索按 C04 归档时标依次绘制 81 个真实状态，直到 60.00 s 的末帧。默认 2×，速度、暂停、时间拖动和重播集中在「物理时间」下。全屏画面同步标注当前归档时刻。七章讲解使用自己的进度与倍速。无 WebGL2 的设备在第一章播放由相同 81 个时刻编成的固定视角录像。

本机 Edge 对打包页的一次全程测试耗时 30.24 秒。从 step 1 到 step 1001，81 次换帧的 WebGL 几何索引数量、步号和画面时标逐项匹配归档。末帧停留后重播回到 step 1。另核对了不同倍速、切章后重新进入和七章讲解的独立进度。

## r4 的三维流场起点

首次打开或重新进入第一章，场景显示 C04 的 0.00 s / step 1。点播体场按原始归档时标推进，第二、第三帧分别是 0.24 s / step 5 和 0.48 s / step 9。第一章自动讲解与配套视频也从零时刻观察尾流的发展。模型滚动对照单独使用 step 835 作为带全分辨率数据的参考帧。

## r3 的 FM 单步推演

第 06 章使用一个合成 Token 的三个特征演示八步 Euler 积分，步长为 0.125。在普通 FM 中步长条件 d=0。第一个特征按教学速度 v = 1 − 0.5z + 0.25τ 逐步更新。前两步的落点为 0.3125 和 0.421875，第二步在新的状态上重算，得到速度 0.8750。页面可分别查看普通推演、训练用的直线速度标签，以及可选的 Shortcut 自蒸馏比较。

配套 PPT 第六页、成片第六章及中文旁白使用同一算例。第 04 章另可使用 C04 的实测统计把示例读数换算回物理单位，第 07 章可观察每次回填前后窗口中的四个求解器步号。

## 卡顿复现和修正

旧版在相机转动时能频繁绘制，但“播放体场”硬性等待 420 ms 才允许换帧。在 50.04–52.92 s 密集段，实际相邻归档间隔为 120 ms。旧版还会为了底部四张切片读取约 16.9 MB 的三维标量资源。新版使旧网格保持可见，下一帧就绪后切换，并附带由最高可用精度的中面数据导出的四通道无损预览。默认时刻首次读取索引和切片图合计约 62 KB。

以下 r2、r3 的历史测试使用 50.04–53.04 s 的成熟尾流密集段，每个源时刻持续 0.12 s。r4 首章从 0.00 s 出发。“播放体场”可以经过全部 81 个时刻，稀疏区段保持当前样本。拖动时间轴以秒定位，方向键可以逐归档帧查看。

Codex 内置窗口在本机的可见页测试中出现过绘制期间每秒仅约一次的动画回调。页面现仅在有内容变化时绘制，在可见窗口的回调逾期时通过另一条浏览器计时路径推进显示，切入后台时停用。持续超出帧预算时会降低像素密度、体采样步数和流线密度。相机旋转、GPU 绘制提交、实际更新到的新 CFD 时刻和设备最终呈现是不同测量。

## 数据、交互和素材

- 对照网络存储 E 盘上的 81 个原始 NPZ，重新校验 1,188 个资源。四个物理通道、导出涡量、全部保存的体素与精度等级、三种掩码、时标、坐标轴和六维统计均通过核验。9 个归档时刻提供原分辨率 FP32，81 个时刻均提供覆盖全域的 LOD 2/4。
- 新的 81 张四通道中面预览，共 1,990,656 个 RGB 像素，含 22,464 个掩码像素。独立计算的色值逐字节一致。另核对了非中面插值与有效掩码，并验证降低画质后保持物理时刻。
- 桌面回归覆盖七章选择、相机、全屏、截图、通道和精度切换、局部控制、主时间轴、暂停与快进。最终发布地址已从头到尾以 2× 播放 142 秒讲解，七个章节依次出现并正常结束。模拟可见窗口每秒只有一次显示回调时，也能按归档节奏推进。软件光栅器采用轻量分辨率，限制未完成的 GPU 绘制，避免换章时堆积。禁止加载站外资源的本地 HTTP 测试通过。关闭 WebGL 后会使用本地七章视频，支持章内和跨章跳转。
- PPTX 为七页可编辑的 16:9 演示文稿。视频为 1920×1080、H.264、30 FPS，带普通话旁白。第一章逐一核对了 561 个视频帧，旁白与后六章编码数据和时标复核一致。包内原版 V1.4 HTML 及 V1.2 SVG 与展示目录的原始文件哈希一致。
- 实际训练检查点未随项目提供。目前已验证潜变量和预测切片的导入、拒绝不匹配数据及误差计算。真实模型的三维重构、长程预测精度和会场设备性能仍待相应数据与设备实测。

## Visual pass r8 · chapters 02–07

本轮针对除真实尾流外的六章模型场景做了轻量视觉强化。每个 `Stage` 增加低对比度动态空间背景与椭圆导视线，保持低几何开销。第 05 章增加沿 Clean、K/V、Query、速度头和统计头移动的状态包及脉冲光环。第 07 章增加 H=10、50、100 三条滚动时间轨道和当前步游标，与四帧 FIFO 回填区域保持同一屏幕坐标。模型检查器增加统一的层级卡片、状态边框与选中按钮动效。

验证结果：`tsc --noEmit` 通过，`check_fm.py` 通过，`check_viewer.py --full-tour` 通过七章巡检、60 秒尾流播放、2× 全程导览、移动宽度和离线回放检查。

## Rendering pass r9 · call-count and label upload reduction

本轮在不改变 WebGL2 主架构的前提下，减少模型章节的低对比度几何边线。透明体素壳体已经由网格线和流程线提供轮廓，低于 0.28 不透明度的 `chip` 不再创建独立 `EdgesGeometry`，避免额外的 LineSegments 绘制。章节标题纹理改为按标题与颜色缓存，切章时复用 CanvasTexture，减少重复测量、栅格化和纹理上传。

本机 Edge 157、RTX 5060、1920×1080 全屏基准中，第 2–7 章中位 draw calls 从 34/13/63/66/58/55 降为 30/13/56/60/54/54，帧间隔 P95 仍为 4.8–4.9 ms，长任务为 0。第一章 Q 播放和体场渲染保持正常。
