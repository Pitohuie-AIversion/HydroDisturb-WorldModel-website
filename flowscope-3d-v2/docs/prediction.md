# 第七章的模拟预测与模型输出

自由探索默认比较 C04 的真实尾流与教学模拟的中央 Z=32 切片。模拟根据 step 835（50.04 s）构造固定的三维输运速度。尾流的流向输运速度取来流的 0.68 倍，横流、展向分别取起始流场对应分量的 0.2 倍，圆柱近旁与外侧边界平滑过渡到静止。沿该速度场用中点法反向回溯，再三线性插值起始帧的 u、v、w、p；压力在这个教学近似中也随流输运。右侧可下载 H=10 的模拟三维场，四通道各有 64 × 96 × 192 个体素。

比较从第一个归档未来步 step 837 打开，H 可取 10、50、100，k 可调到区间内任意一步。只有目标时刻和真值归档一致时，才显示两条剖线、逐点绝对误差和切片有效网格的 RMSE。模拟对照使用当前显示采样网格；目标步缺档时，左侧显示前一归档时间，右侧仍显示目标时间。

模拟在 k=0 至 100 共生成 101 个时刻，间隔 0.06 s，其中 28 个有同一时刻的真值归档。[模拟数据清单](../data/simulated-rollout/manifest.json) 记录各切片的来源、单位、尺寸、时刻和校验值。每帧以 gzip 压缩，解压为小端 float32，轴序 [通道,Y,X]，无效体素为 NaN。[H=10 的三维 NPZ](../data/simulated-rollout/step-0845-volume.npz) 同时包含四通道、三轴坐标、有效掩码和起始归档标识。在展示工程目录运行 `python scripts/generate_simulated_rollout.py` 可重建数据，需要 NumPy 和 SciPy。

## 导入已训练模型的预测切片

在训练环境离线解码模型输出，使用同一次推理导出的潜状态和六维统计恢复物理单位。将一帧预测保存为 NPZ，再生成场景 07 可读取的 JSON。工具会读取 checkpoint 字节计算 SHA-256。

| NPZ 字段 | 约定 |
| --- | --- |
| `prediction` | 浮点数组 `[4,64,96,192]`，按通道、展向、横流、流向存储 |
| `channels`、`units` | 字符串数组 `["u","v","w","p"]` 和 `["m/s","m/s","m/s","Pa"]`，其中 v 为横流、w 为展向 |
| `x_m`、`y_m`、`z_m` | 分别为 192 个流向、96 个横流和 64 个展向体素中心坐标，对应 C04 源数组 `x`、`z_cross`、`y_span` |
| `start_step`、`step`、`time_s` | 两个整数标量和一个物理时间标量。本演示使用 step 835 为起点，H=10/50/100 对应 845/885/935 |
| `valid_mask` | 可选布尔数组 `[64,96,192]`。提供时逐点与归档有效域对齐 |
| `checkpoint_sha256`、`truth_source_sha256` | 可选字符串标量。提供时分别与 checkpoint 文件和归档的原始帧标识核对 |

从展示项目目录运行以下命令，路径换成训练运行生成的文件。

```powershell
python scripts/export_prediction.py --prediction forecast_845.npz --checkpoint model.pt --channel u --out forecast_845_u.json
```

在「未来恢复与滚动」中选择「导入模型预测切片」。工具核对网格坐标、通道、单位、全分辨率有效域和物理时标后导出 z=32 的 YX 切片。视图采用同一相机与固定色标对照真值和预测，且只对该切片有效体素计算 RMSE。误差视图显示绝对误差，单位随通道切换。
