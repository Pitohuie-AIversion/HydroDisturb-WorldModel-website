# FlowScope 3D 网页互动分镜

七章顶部保留同一条 C04 数据线索。它显示当前物理时间、求解器步号、Token 对应的原网格空间块、真实归档统计量和四个物理字段。第一章随 81 个真实归档帧更新，第七章随滚动目标显示归档参照。模型章节继续沿用同一 C04 参考帧和同一空间块。

## 01　跟住一次涡脱落

从物理 0.00 秒入场，固定正交视角观察圆柱两侧。首播约 8 秒，依次经过 C04 的 81 个归档时刻，到 60.00 秒停住。屏幕上读的是物理时间。

首播后，点击「下侧正涡」的两张切片。在 Z = 32 的同一截面上，涡量峰从 X = 0.422 m 移到 0.572 m。再点「上侧负涡」两帧，对照另一侧从 0.384 m 移到 0.609 m 的过程。底色表示横流速度 v，圆环标出由 u、v 计算的展向涡量局部峰。两组记录给出脱落后的对流位置，脱离圆柱壁面的瞬间仍需结合原场判断。

## 02　选一块流体，跟着网格折叠

在圆柱下游点一块流体，记下左侧的 Z、Y、X 追踪格点。沿过程带从 Stem 切到三次 S2C，每次观察三条轴减半、通道数增加。最后选中的 Token 对应输入网格上的一个 8 × 8 × 8 块。卷积的感受野还会延伸到相邻区域。

## 03　在同一位置展开 256 维特征

切到第三章，核对所选 Z、Y、X。按「特征截面」，改变通道，读同一 Token 在该维度的数值。切换 RMSNorm 观察归一化效果，再进入「物理探针」辨认拟能和能谱两个诊断目标。默认向量来自教学示例，导入匹配的潜变量后可检查真实模型输出。

## 04　顺着 Token 找回原来的流体

进入解码章，保持前章选区。沿 C2S 看空间网格逐级恢复；在读出端分别追踪矢量势经 Curl 得到的速度和独立压力。下一步接上六维统计旁路恢复物理量，最后检查流体掩码和差分模板的有效区域。

## 05　用两个 Query 验证因果关系

把上排 Clean 四个历史时刻和下排 Query 对齐着读。先点下排最早的 Query，再点最后一个；分别数出一帧和四帧可读 K/V。切换到「训练」，找出监督标签所处的支路，再回「推理」检查未来真值是否进入读取范围。

## 06　在同一个物理步走完八次积分

固定历史条件和预测的物理时刻。观察初始潜状态，按「下一步」重新计算 Query 和速度。第一步从 0.20 出发，以 Δτ = 1/8 乘速度 0.90，到达 0.3125。继续点击到 τ = 1，观察每个新落点怎样成为下一次积分的起点。坐标轴上的轨迹是教学算例。

## 07　回填四帧窗口，在相同位置检验预测

打开自由探索，从 step 837 的横流速度看起。左图是 C04 真值，右图是从 step 835 的三维初始场外推的教学模拟。沿相同的 X 剖线比较两条曲线，切换到绝对误差查看偏差分布。选择 H = 10、50、100 或逐步推进 k，观察四帧窗口移出最早一帧并写入新帧。目标步缺档时左图退到前一归档，右图保留目标步的模拟场，此时关闭同帧误差。导入匹配的模型预测切片后，相应步号和通道会显示导入结果。五分半长版导览保留了等待导入独立预测的原分镜。
