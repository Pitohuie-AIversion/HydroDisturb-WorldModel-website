# HydroDisturb-WorldModel Website (FlowScope 3D)

Interactive 3D flow-field visualization and presentation website for **[HydroDisturb-WorldModel](https://github.com/Pitohuie-AIversion/HydroDisturb-WorldModel)** and **[HydroDisturb-Bench](https://github.com/Pitohuie-AIversion/HydroDisturb-Bench)**.

## Structure

- `flowscope-3d-v2/`: Vite + TypeScript + WebGL2/Three.js interactive 3D wake visualization application, data assets, scripts, and docs.

## Local Development

```bash
cd flowscope-3d-v2
npm install
npm run dev
```

## Production Build

```bash
cd flowscope-3d-v2
npm run build
```
